# Reglas heredadas de compatibilidad

Este archivo se conserva por compatibilidad con referencias antiguas, pero ya no es la autoridad normativa del repo.

## Fuente de verdad vigente

Lee las reglas en este orden:

1. `memory/constitution.md`
2. `memory/sase-canon.md`
3. `AGENTS.md`

## Reglas minimas que siguen vigentes

1. Responder en español salvo instruccion explicita en otro idioma.
2. No subir secretos, tokens de servicio ni credenciales reales al repositorio.
3. No dejar perfiles de navegador, caches pesados, `.tmp`, `.bak` o respaldos sensibles dentro del repo.
4. No hacer cambios destructivos o de alto impacto sin contexto y validacion suficiente.
5. Mantener la arquitectura actual mientras no exista un expediente en `specs/` que justifique un cambio mayor.
