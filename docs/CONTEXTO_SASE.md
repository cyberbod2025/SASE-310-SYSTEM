# Contexto funcional heredado

Este archivo conserva contexto historico del producto, pero ya no actua como autoridad unica para decisiones tecnicas o de IA.

## Consulta vigente

Para decisiones actuales, usa este orden:

1. `memory/constitution.md`
2. `memory/sase-canon.md`
3. `AGENTS.md`
4. `PRD.md`
5. El expediente activo en `specs/`

## Regla de uso

- Usa este documento como contexto narrativo e historico.
- Usa el canon y las specs como base normativa y de ejecucion.
- Si este archivo contradice el producto real, manda primero el canon y despues el codigo/configuracion ejecutable.
