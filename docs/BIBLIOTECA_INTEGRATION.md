# Integracion con biblioteca externa

Este archivo queda como referencia historica. La biblioteca externa puede servir como apoyo, pero no define por si sola las reglas de SASE.

## Autoridad vigente

Antes de usar workflows externos o conocimiento compartido, consulta:

1. `memory/constitution.md`
2. `memory/sase-canon.md`
3. `AGENTS.md`

## Nota operativa

- Los atajos bajo `.agents/workflows/` son heredados y pueden estar desactualizados.
- Cualquier workflow externo o biblioteca compartida debe adaptarse a la realidad del repo actual antes de ejecutarse.
- Si un workflow externo contradice el canon local, manda el canon local.
