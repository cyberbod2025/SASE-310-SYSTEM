# Bienvenido al Piloto SASE-310 (v2.4.0)

Este es el sistema oficial de gestión y control escolar para la Escuela Secundaria Técnica 310.

## Accesos Oficiales

- **URL del Sistema:** `[PENDIENTE DE DESPLIEGUE]`
- **Soporte Técnico:** Soporte IT (Interno) - `[PENDIENTE]`

## Credenciales de Acceso

El piloto opera con **cuentas institucionales reales**.
Para acceder, utilice su correo electrónico registrado y la contraseña asignada por la Dirección.

> **Nota de Seguridad:** El acceso es personal e intransferible. Si no cuenta con sus credenciales, solicítelas directamente en la oficina de Dirección Técnica.

## Acceso Móvil

El sistema es una **Progressive Web App (PWA)**, diseñada para funcionar como una aplicación nativa en su celular.

## Funcionalidades Activas

1.  **Tablero de Control:** KPIs en tiempo real.
2.  **Registro de Incidencias:** Reportes de conducta, retardo, uniforme y salud.
3.  **Expediente Digital:** Vista 360 del alumno (limitada por rol).
4.  **Justificantes:** Emisión y validación digital.
5.  **Solicitud de Registro:** Flujo de alta para nuevo personal.

## Soporte Móvil

El sistema es **Progressive Web App (PWA)**. Puede instalarlo en su celular:

1.  Abra Chrome en Android o Safari en iOS.
2.  Seleccione "Agregar a Pantalla de Inicio".
3.  El icono de SASE aparecerá como una app nativa.

## Reporte de Fallos

Use el botón flotante de **Feedback** (?) en la esquina inferior derecha para reportar cualquier error o sugerencia directamente al equipo de desarrollo.
