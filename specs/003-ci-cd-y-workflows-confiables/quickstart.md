# Quickstart - 003 CI/CD y Workflows Confiables

## Verificaciones locales equivalentes

- `pnpm install --frozen-lockfile`
- `pnpm lint`
- `pnpm type-check`
- `pnpm test`
- `pnpm build`
- `pnpm test:visual:glass`
