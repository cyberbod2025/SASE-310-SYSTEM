# Design System: Luminous Refraction — SASE Abril 2026

## North Star: "The Radiant Prism"

## Palette
- Primary (Electric Lavender): #7B61FF
- Secondary (Cyan Glow): #00F5FF
- Tertiary (Soft Pink): #FF79C6
- Background (Neutral): #F0F8FF

## Rules
- No 1px solid borders (No-Line Rule)
- Glass surfaces at 30-60% opacity + backdrop-blur(20-40px)
- Signature gradient: primary → secondary at 45°
- Compact spacing (Level 2)
- Maximum roundedness (Level 3) for interactive elements
- NO dividers, NO flat grey shadows
- Shadows: 40-60px blur, 4-8% opacity, tinted with primary

## Typography
- Headlines: Space Grotesk (geometric, futuristic)
- Body/Labels: Inter (humanistic clarity)
- High-contrast scale jumps between display and body

## Depth Layers
1. Base: Bright mesh gradients (secondary + tertiary orbs)
2. Section: Semi-transparent neutral 40% + blur
3. Active/Card: 70% opacity surfaces

## Components
- Buttons: 3D glass bead, pill shape, internal glow
- Cards: No dividers, frosted edges, light-catching refraction
- Inputs: Semi-transparent, 20px blur, secondary glow on focus
